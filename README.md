# upay Smart Cash-Flow Copilot

**Team:** Tristack
**Event:** AI Dev Fest 2026, AI Hackathon (DIU CPC × upay)
**Track:** Track 03, Customer Innovation & Financial Independence

## What it is

An AI feature for the upay wallet that warns users before they run
short of money at month-end, explains why in বাংলা and English, and
suggests what to do next.

## Planned features

- Month-end shortfall warning
- Cash-out fee saver
- Safe savings planner

## Tech stack

Python, FastAPI, XGBoost, SHAP, Next.js

## Status

In development. All data is simulated. No real upay customer data is used.
